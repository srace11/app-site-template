# app-site-template

Astro template for a single app's mini-site on `appname.shaneracey.com`: a one-scroll landing page (hero, video, how it works, features, coming soon, about, pricing, FAQ), an optional waitlist, privacy policy, terms and support page, all driven by `src/app.config.ts`.

See [SETUP.md](SETUP.md) for deployment, DNS and the new-app launch checklist.

```sh
npm install
npm run dev
```
